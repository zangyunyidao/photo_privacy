# Issue #4：WebP 检查与清理实施计划

> 实施状态：RIFF/位流属性解析、Exif/XMP 清理、动画和透明度保留、Wasm 网页接入
> 及自动测试已在 `feat/webp` 完成；剩余浏览器人工验收、推送、合并与 Pages 部署。

## 目标与边界

Issue #4 将为有损、无损、透明和动画 WebP 建立与 JPEG/PNG 相同的完整闭环：
检查 RIFF 容器及图像属性，展示 Exif/XMP 等隐私信息，在不解码或重压缩像素的
情况下生成清理副本，并对输出重新解析验证。

首版不会修改画面、优化压缩率或解释任意应用私有数据。已知渲染块原样保留；
未知块默认删除并列入报告，因为 WebP 读取器按规范应忽略未知块，而本项目的明确
目的就是清理非显示必需数据。

## 阶段一：RIFF 块模型与安全解析

新增 `webp.mbt` 和 `webp_test.mbt`：

- 校验 `RIFF`、小端文件长度和 `WEBP` 标识。
- 遍历 FourCC、块长度、数据及奇数长度的零填充。
- 对所有长度和偏移做边界检查，并限制块数量。
- 报告 RIFF 声明范围后的尾随数据。
- 识别 `VP8 `、`VP8L`、`VP8X`、`ALPH`、`ICCP`、`EXIF`、`XMP `、
  `ANIM`、`ANMF`，以及实际文件中可能追加的 `IART`、`ICOP`、`INAM`、
  `ICMT` 等传统 RIFF 信息块。

## 阶段二：图像属性、Exif 与动画

- 从 `VP8 `、`VP8L` 或 `VP8X` 读取画布宽高。
- 报告有损、无损或扩展编码、透明度及动画状态。
- 校验 VP8X 保留位和功能标志与实际块的一致性。
- 读取动画循环次数、帧数量，并安全检查 ANMF 内部块。
- 复用 `exif.mbt` 解析 WebP EXIF；同时接受 TIFF 数据和带 `Exif\0\0`
  前缀的兼容输入。
- 把 ICC 配置归为显示信息，把 EXIF/XMP 归为可移除隐私信息。

## 阶段三：无损结构清理与复检

- 原样复制 VP8/VP8L 位流、ALPH、ICCP、ANIM 和 ANMF 渲染数据。
- 删除 XMP、非显示必需 Exif、未知顶层块和 ANMF 内未知块。
- 方向会影响显示时，仅保留最小 Exif 方向数据。
- 根据实际输出修正 VP8X 的 EXIF/XMP 标志和 RIFF 总长度。
- 正确重建奇数长度填充，删除 RIFF 范围后的尾随数据。
- 再次解析输出，确认目标元数据消失且重复清理结果一致。

## 阶段四：Wasm 与网页接入

- 在现有签名分派中加入 `Webp -> inspect_webp / sanitize_webp`。
- 页面显示 WebP 块数、编码类型、透明度、动画、帧数和循环次数。
- 清理副本使用 `image/webp` 和 `.clean.webp`。
- 删除报告展示 EXIF、XMP、未知块和 RIFF 尾随数据。
- 增加 WebP Wasm 端到端测试。

## 阶段五：验收与文档

自动测试覆盖简单有损、简单无损、透明、扩展、动画、Exif/XMP、ICC、未知块、
奇数填充、错误 RIFF 长度、截断输入、标志不一致、清理后复检和幂等性。

浏览器人工验收使用有损、无损、透明、动画和带元数据 WebP，逐一完成选择、检查、
清理、下载、正常显示和重新上传复检。样例不得包含真实个人隐私。

# PhotoPrivacy 项目申报书

## 1. 项目名称和 GitHub 仓库地址

- 项目名称：PhotoPrivacy
- GitHub：<https://github.com/zangyunyidao/photo_privacy>

## 2. 项目简介

PhotoPrivacy 是一个以 MoonBit 为主要实现语言的本地图像元数据检查与隐私清理工具。图像文件除了可见画面外，还可能携带拍摄位置、拍摄时间、设备型号、编辑软件、作者和文本注释等信息。项目计划让用户在浏览器中拖入或选择本地图像，查看文件的真实格式、图像属性和可识别元数据，并生成移除非显示必需元数据的副本。核心处理将编译为 WebAssembly，在浏览器本地完成，不上传用户图像。

## 3. 项目方向与适用场景

项目属于“应用与内容工具”方向，同时涉及二进制文件解析和 WebAssembly 应用。适用于在社交平台、论坛、邮件或公开数据集中分享图片前检查隐私信息，也可作为学习图像容器格式、Exif 元数据和本地 WebAssembly 文件处理的示例工程。项目面向普通用户、内容创作者、研究人员及需要公开图像资料的开发者。

## 4. 拟实现的核心功能

1. 根据文件签名而不是扩展名识别 JPEG、PNG、WebP、GIF、BMP、TIFF、HEIF/HEIC 和 AVIF；其中 JPEG、PNG、WebP 为本期重点支持格式。
2. 以带边界检查的方式解析 JPEG 段、PNG 块和 WebP RIFF 容器，遇到截断、异常长度或不受支持结构时返回明确诊断，而不是崩溃或静默处理。
3. 提取并分类展示图像尺寸、编码属性、Exif、XMP、IPTC、GPS、时间、设备、软件和文本注释等信息，并说明可能的隐私风险。
4. 清除 JPEG、PNG、WebP 中非显示必需的已支持元数据，尽量保留原始图像数据、透明度和动画等显示效果；对可能影响方向或色彩表现的字段给出提示。
5. 清理后重新扫描输出文件，列出删除和保留的结构，验证受支持的隐私元数据已经消失，并允许用户下载清理后的图片。
6. 提供 MoonBit 公共库、命令行示例、自动测试和静态 WebAssembly 页面；网页支持拖放、手动选择、预览、检查报告、清理和下载，整个过程不依赖账号、数据库或远程图像处理服务。

## 5. 项目来源与开源说明

本项目为原创项目，不是现有项目的直接移植。实现时将依据 CIPA Exif 3.1、W3C PNG 第三版规范和 Google WebP RIFF Container Specification 等公开技术规范设计数据结构与解析逻辑，并使用独立编写或具有明确许可的最小测试样例进行验证。若后续参考其他开源项目的测试方法或行为，将在仓库中记录项目名称、来源链接、许可证和具体参考范围，不复制来源不明或许可证不兼容的代码。项目采用 Apache-2.0 许可证开源。

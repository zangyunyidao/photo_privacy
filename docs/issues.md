# PhotoPrivacy GitHub Issues 设计

项目按五个可独立验收的 Issue 推进。JPEG 是必须完成的主线，PNG 是第二优先级，WebP 在时间不足时可以保留为扩展目标。

## Issue 1：实现通用二进制读取与图像信息模型

**建议标签：** `基础设施`、`安全`、`优先级：高`

**状态：** 已完成（分支 `feat/binary-reader`）

### 背景

图像文件是不可信的二进制输入。JPEG、PNG、WebP 和 Exif 都需要读取长度、偏移与不同字节序的数据，同时浏览器和 CLI 需要使用统一的图像信息、元数据、风险与诊断结构。

### 工作内容

- 实现带游标的安全二进制读取器。
- 支持 `u8`、大端/小端 `u16` 和 `u32`、切片、跳过与定位。
- 失败时返回包含位置和长度的结构化错误，且不移动游标。
- 定义统一的图像尺寸、元数据分类、隐私风险、处置方式和诊断模型。
- 对内部数组进行防御性复制，避免报告生成后被外部修改。

### 验收标准

- 所有读取操作在访问数据前完成边界检查。
- 空输入、末尾读取、非法位置、负数长度和截断输入均有测试。
- 恶意长度不会导致崩溃、死循环或巨量内存分配。
- 公共数据模型可以同时承载 JPEG、PNG 与 WebP 的检查结果。
- `moon check` 与 `moon test` 通过。

## Issue 2：实现 JPEG/Exif 信息检查与清理

**建议标签：** `JPEG`、`Exif`、`核心功能`、`优先级：高`

**状态：** 已完成并合并至 `main`

### 工作内容

- 扫描 SOI、APPn、COM、SOF、SOS 和 EOI 等 JPEG 标记。
- 读取宽度、高度、位深、分量数和段清单。
- 解析大端/小端 TIFF、IFD0、Exif IFD 与 GPS IFD 常见标签。
- 提取 Exif、XMP、IPTC、设备、时间、方向、GPS 和注释信息。
- 删除非显示必需元数据，保留压缩扫描数据并生成清理报告。
- 清理后再次解析，验证结构有效且目标元数据已经消失。

### 验收标准

- 正常、未知 APP 段、截断、非法长度和异常 IFD 偏移均有测试。
- 能显示常见设备、时间、方向和 GPS 信息。
- 无损结构清理模式不改变 JPEG 压缩扫描数据。
- 重复清理得到相同结果，输出能够正常显示。

## Issue 3：实现 PNG 信息检查与清理

**建议标签：** `PNG`、`核心功能`、`优先级：中`

**状态：** 已完成、合并至 `main` 并部署 Pages

### 工作内容

- 解析 PNG 签名、块长度、块类型、数据与 CRC。
- 读取 IHDR，并识别文本、时间、Exif、色彩和动画块。
- 按策略移除 `eXIf`、`tEXt`、`zTXt`、`iTXt`、`tIME` 等块。
- 保留关键块、透明度、必要色彩信息与 APNG 动画结构。
- 重算 CRC，并对清理结果进行二次解析验证。

### 验收标准

- 能报告未知块、非法顺序、异常长度和 CRC 错误。
- 不删除解码必需的关键块。
- 静态 PNG、带文本 PNG 和 APNG 均有测试。
- 清理后的文件结构有效并能正常显示。

### 当前验证结果

- MoonBit 测试覆盖静态、透明、文本、Exif、未知块、尾随数据和 APNG 结构。
- Wasm 桥接已覆盖 PNG 检查、清理、下载字节与清理后二次检查。
- 普通 PNG 测试样例使用真实 zlib 压缩像素数据，清理时 IDAT 原样保留。
- 普通 PNG、透明 PNG 和 APNG 已完成检查、清理、下载与清理后显示验证。

## Issue 4：实现 WebP 信息检查与清理

**建议标签：** `WebP`、`扩展功能`、`优先级：中`

**状态：** 开发中（分支 `feat/webp`）；具体阶段见 [WebP 实施计划](webp-implementation-plan.md)

### 工作内容

- 校验 RIFF/WEBP 头并遍历 FourCC 块。
- 识别 VP8、VP8L、VP8X、ALPH、ANIM、ANMF、EXIF、XMP 与 ICCP。
- 移除 EXIF/XMP，修正 RIFF 长度及 VP8X 元数据标志。
- 保留透明度和动画相关结构，并对输出进行复检。

### 验收标准

- 支持有损、无损、透明和动画 WebP 的结构报告。
- 正确处理奇数长度块的填充与 RIFF 总长度。
- 清理后文件能够正常显示，动画和透明度不被破坏。

## Issue 5：实现 WebAssembly 网页与最终验收

**建议标签：** `WebAssembly`、`界面`、`演示`、`优先级：高`

**状态：** JPEG、PNG 已合并并部署；WebP 开发中

### 工作内容

- 构建拖放和手动文件选择区域，并显示本地图像预览。
- 将浏览器 `ArrayBuffer` 交给 MoonBit/Wasm 检查与清理接口。
- 展示真实格式、图像属性、元数据、风险、诊断和清理报告。
- 使用 Blob 下载输出文件，并释放不再使用的对象 URL。
- 在 Issue 2 完成后先接通 JPEG 全流程，再逐步接入 PNG 和 WebP。
- 完善 README、测试样例、CI、GitHub Pages 和可复现验收步骤。

### 验收标准

- JPEG 完成“选择—检查—清理—复检—下载”的完整闭环。
- 已完成的其他格式可接入同一界面；未支持格式会明确拒绝清理。
- 页面无需账号、后端或远程图像处理 API，图片不会离开浏览器。
- 新环境按照 README 可以构建、测试并打开演示。
